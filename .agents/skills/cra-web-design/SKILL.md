# CRA Web Design Guidelines

Design standards and visual identity for PT Cahaya Restu Amanah.

## 1. Visual Identity & Palette
- **Primary Colors**:
  - Deep Black (`#0B0B0B` / `#121212`) for backgrounds and strong contrast bases.
  - Elegant Gold (`#D4AF37` / `#C5A059` / `#E5C158`) for accents, primary CTAs, borders, and badges.
  - Clean White / Off-White (`#FFFFFF` / `#F8F9FA`) for body text and readable content surfaces.
  - Neutral Muted (`#8A8A8A` / `#262626`) for subtle borders and secondary text.
- **Typography**: Clean, professional sans-serif (e.g., Inter or Outfit) with clear hierarchy.
- **Aesthetic**: Modern, professional, and elegant. Avoid cluttered flyer layouts; use structured grids, generous whitespace, and subtle micro-interactions.

## 2. Responsiveness & Layout
- Mobile-first approach: optimized for smartphones, tablets, and desktops.
- Standard container widths with adaptive padding (`px-4 sm:px-6 lg:px-8`).
- Touch-friendly targets: buttons and clickable elements must have a minimum size of 44x44px.

## 3. Accessibility (a11y)
- **Contrast**: Gold text must only be used on dark backgrounds if contrast ratio meets WCAG AA (≥ 4.5:1). For bright backgrounds, use dark gold/amber or dark text.
- **Semantics**: Use appropriate HTML5 tags (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`).
- **Media**: Provide descriptive `alt` text for all images.
- **Reduced Motion**: Respect `prefers-reduced-motion` for animations.

## 4. Indonesian Content & Tone
